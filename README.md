# 计算传播学图谱式学习平台

这是一个基于 React + Vite + Tailwind CSS 的静态学习网站。网站围绕知识图谱、问题图谱、能力图谱和岗位能力图谱组织计算传播学课程内容，所有学习材料均写在前端，不依赖后端、数据库或登录系统。

## 运行方式

```bash
npm install
npm run dev
```

打开终端输出的本地地址即可访问。

## 页面内容

- 首页：四大图谱入口与学习路径总览
- 知识图谱：10 个章节、论文研究、项目实战，每个章节可打开完整学习卡片
- 问题图谱：六类传播问题，展示数据、方法、图表与论文表达方式
- 能力图谱：12 项学习能力，连接章节、工具、任务和评价标准
- 岗位能力图谱：6 类岗位方向，展示课程知识与典型任务
- 方法工具箱：15 种常用计算传播学方法
- 项目实战：10 个课程项目案例
- 资源页：学习工具、Python 库和数据来源
- 关于课程：课程定位、学习方式和教学展示建议
